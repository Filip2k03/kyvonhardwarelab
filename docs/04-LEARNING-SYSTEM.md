## Lesson Model

Every lesson contains:

1. Objective
2. Prerequisites
3. Theory
4. Visual explanation
5. Required hardware
6. Safety
7. Wiring
8. Prediction
9. Firmware
10. Code walkthrough
11. Physical experiment
12. Expected result
13. Measurements
14. Common mistakes
15. Debugging
16. Challenge
17. Quiz
18. Mini project

## Educational Rule

Never teach only:

"Connect this and copy this code."

Explain why the circuit and firmware work.

Students should predict behavior before executing an experiment.
