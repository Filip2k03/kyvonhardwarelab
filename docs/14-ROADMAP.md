# Roadmap

## V1 — Personal Lab Companion

Frontend-only interactive learning environment.

Phases:

| Phase | Focus |
|-------|--------|
| 01 | Foundation — Vite/React/TS shell, routing, design tokens |
| 02 | Hardware knowledge base |
| 03 | Learning engine + local progress |
| 04 | SVG circuit engine |
| 05 | Engineering tools / calculators |
| 06 | Lazy-loaded 3D lab (one excellent model first) |
| 07 | Project library |
| 08 | Handouts / print mode |
| 09 | Release QA |

See also `docs/16-KNOWN-LIMITATIONS.md` for accepted V1 constraints after Phase 09.

## V1 Non-Goals

- Accounts / auth
- Backend / database
- Cloud sync
- SPICE simulation
- Marketplace / commerce
- Native mobile apps

## Post-V1

| Phase | Focus |
|-------|--------|
| 10 | Living dashboard from local progress |
| 11 | Enrich circuit library (buzzer, relay, IR, LDR, stepper) |

## Near-Term After V1

- Expand curriculum depth for existing lessons
- Add remaining kit components to 3D inspection
- Improve handout templates per lesson family
- Lighthouse budget monitoring in CI

## Later Candidates

- Optional offline PWA packaging
- Instructor mode for classroom handouts
- ESP32-focused IoT deep tracks
- Robotics expansion projects 26–30 with physical chassis guides
- Optional sync — only if product requirements change

Do not pull later candidates into V1 implementation without an explicit phase update.
