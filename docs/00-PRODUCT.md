# Product Specification

## Product

KYVON Hardware Lab

## Vision

A personal interactive electronics laboratory for learning embedded systems
through physical experimentation.

The learner owns real hardware.

The website accompanies the physical hardware rather than replacing it.

## Primary Loop

```
LEARN
↓
UNDERSTAND
↓
WIRE
↓
PREDICT
↓
PROGRAM
↓
BUILD
↓
MEASURE
↓
DEBUG
↓
IMPROVE
```

## Primary Areas

### Dashboard

Shows:

- current lesson
- learning progress
- recently viewed components
- unfinished experiments
- completed projects
- bookmarks

### Learn

Structured curriculum from electronics fundamentals through robotics and IoT.

### Components

Searchable hardware encyclopedia.

### Circuits

Interactive wiring diagrams.

### Lab

Interactive simulations and experiments.

### 3D Explorer

Inspectable hardware models.

### Projects

Complete physical projects.

### Tools

Engineering calculators and converters.

### Handouts

Printable A4 laboratory worksheets.

### Progress

Local learning history and achievements.

## V1 Constraints

Frontend only.

No account.
No backend.
No database.
No cloud synchronization.

Persistence uses localStorage with JSON import/export.
