# Handout System

Every lesson and project must support Print Mode.

Target:

- A4 portrait
- browser print
- Save as PDF

## Handout Layout

```
KYVON HARDWARE LAB

Lesson / Project
Name:
Date:

OBJECTIVES

THEORY

COMPONENTS

CIRCUIT

PREDICTION

PROCEDURE

MEASUREMENTS

OBSERVATIONS

DEBUGGING

CHALLENGE

NOTES
```

## Print Requirements

Hide:

- navigation
- buttons
- interactive controls
- animations

Avoid content clipping.

Avoid splitting important circuit diagrams across pages.

Use high-contrast print-friendly styling.

Do not require a server-side PDF generator in V1.
