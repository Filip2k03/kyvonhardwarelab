# Phase 08 — Handouts

Read `docs/08-HANDOUT-SYSTEM.md`.

Implement Print Mode for lessons and projects.

Build:

- handout route / entry points
- A4 portrait print layout
- browser print + Save as PDF support
- print stylesheet that hides navigation and interactive chrome
- sections: objectives, theory, components, circuit, prediction, procedure, measurements, observations, debugging, challenge, notes
- name / date fields for laboratory worksheets
- page-break rules that avoid splitting critical circuit diagrams

Do not introduce a server-side PDF generator.

Verify print layout at A4 and that interactive controls are hidden.
