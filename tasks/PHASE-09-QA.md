# Phase 09 — Release QA

Perform a complete repository audit.

Do not add new product scope.

Find and resolve:

- TypeScript errors
- lint errors
- broken routes
- dead buttons
- missing states
- duplicated logic
- accessibility failures
- mobile overflow
- layout shift
- unnecessary dependencies
- large bundles
- console warnings
- broken persistence
- broken print layout

Run full validation.

Document any remaining known limitation honestly.
