# Phase 12 — UI Polish

Read `docs/02-DESIGN-SYSTEM.md` and `docs/14-ROADMAP.md` (Post-V1 Phase 12).

Goal: tighten the engineering-lab chrome without turning the app into a marketing site.

Ship:

- shared `PageHeader`, `LabPanel`, `StatusChip`, `MeterBar`
- bench grid atmosphere on the shell (subtle, reduced-motion safe)
- denser list/row hover states and status chips on Learn / Projects / Dashboard
- progress meter on the home lesson count

Do not add glassmorphism, purple marketing themes, or oversized heroes.

Validate with existing UI tests, then lint / typecheck / test / build.
